Политика конфиденциальности

Тоннаж — веб-приложение для дневника тренировок. Регистрации нет.

  • Все данные (тренировки, шаблоны, настройки) хранятся только в браузере вашего устройства (IndexedDB).
  • Мы не собираем, не передаём и не продаём персональные данные. Аналитики, рекламы, куки и внешних шрифтов нет.
  • Сайт размещён на GitHub Pages; хостинг может записывать технические логи обращений (IP-адрес) по своим правилам.
  • Очистка данных браузера удалит дневник. Делайте резервную копию (JSON/CSV) в разделе «Резервная копия».
